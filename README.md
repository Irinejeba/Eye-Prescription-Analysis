# 👁️ Eye Prescription Data Analysis
By C. Irine Jeba

### 📊 Project Overview
Analyzed eye prescription dataset to understand age distribution patterns for targeted eye-care.

### 🔍 My Approach
1. **Data Loading with pandas** - `pd.read_csv()` + cleaned missing values
2. **Visualization with matplotlib** - Fixed overlap using `bins=15` and `edgecolor='black'`
3. **Insights** - Found bimodal pattern: peaks at 25 and 55 years (younger & older adults)

### 🛠️ Tech Stack
- Python, Pandas, Matplotlib, NumPy

### 📈 Key Insight
Two age groups need more eye-care attention - helps clinics plan better!
